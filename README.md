# GPU Acceleration for Environmental Risk Analysis

## 1. Project Title
GPU Acceleration for Environmental Risk Analysis (Heat & Flood).

**Description:** Parallel implementation in **CUDA C++** of a stenciling algorithm to compute the Urban Heat Exposure Index (UHEI).

## 2. Dataset Description (TALEA Project)
The data is derived from the open-source **TALEA** project (Surface Urban Heat Islands Analysis - Bologna). 
Official source: https://github.com/TALEA-platform/suhi/tree/main/.

**Processed Channels:**
- **LST (Land Surface Temperature):** Surface temperature.
- **NDVI:** Normalized Difference Vegetation Index.
- **Albedo:** Surface reflectivity.

**Algorithm:** The software applies a convolution (stencil operation) across the three channels to compute the composite UHEI index for each grid cell.

## 3. Repository Structure and Usage Instructions
Organization of the `data/` directory:
- `data/final_gpu_v5.ipynb`: Main Jupyter Notebook configured for the **Google Colab** environment.
- `data/progetto.zip`: Compressed archive containing the complete C++ source code (`src/`) and **Python** scripts (`scripts/`).
- `data/test_1.zip`: Compressed archive containing the raster and vector datasets.
- `data/Mappa_Bologna_Completa.html`: Dynamic interactive map generated by the `generate_web_map.py` script, overlaying the GPU-computed UHEI risk index with the administrative boundaries of Bologna.

**Execution Workflow:**
1. Open the `data/final_gpu_v5.ipynb` notebook in **Google Colab**.
2. Upload the `data/progetto.zip` and `data/test_1.zip` archives into the runtime environment, keeping them in their compressed format.
3. Execute the initialization cell (Phase 0), which will automatically handle decompression, dependency installation, and directory hierarchy configuration.

## 4. Source Code Structure (src/)
List and description of the files located in `src/`:
- `benchmark_suite.cu`: Main test suite. Implements a dual-timer mechanism to separate kernel execution time from total system time (including PCIe transfer overhead).
- `risk_map_generator.cu`: Production module for generating risk maps and performing numerical validation (RMSE) against the CPU baseline.
- `gpu_optimized_test.cu`: Dedicated module for analyzing transfer latency and memory bandwidth, used for a direct comparison between Pageable Memory and Pinned Memory.
- `kernel_tuning_extreme.cu`: Exploratory test to evaluate the effectiveness of instruction-level optimizations (`__restrict__`, `__launch_bounds__`, `#pragma unroll`) on memory-bound algorithms. Confirms that the bottleneck is memory bandwidth, not computational throughput.
- `profiling_harness.cu`: Minimal wrapper for micro-architectural analysis using NVIDIA Nsight Compute.

## 5. Automation and Visualization (scripts/)
Support toolchain located in the `scripts/` directory:
- `data_preprocessor.py`: Converts raw GeoTIFF/GeoJSON data into raw binary format (float32).
- `run_*.py`: Orchestration scripts for compiling (`nvcc`) and executing the various C++ modules.
- `plot_*.py`: Suite of scripts for generating performance graphs (histograms, roofline models, sensitivity analysis).
- `generate_web_map.py`: Generates the interactive geospatial visualization using Folium.

## 6. System Requirements
- **Environment:** Google Colab (Target GPU: **NVIDIA Tesla T4**).
- **Dependencies:** CUDA Toolkit, Python 3.x (Libraries: Rasterio, Folium, Matplotlib).
